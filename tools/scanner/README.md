# 차트 패턴 스캐너 (개인용)

코스피200 + S&P500 종목의 최신 일봉을 받아, 사이트에서 설명한 차트 패턴이
최근에 발생한 종목을 찾아 HTML 리포트로 만든다.

> **이 도구는 개인 학습용이다.** 결과를 웹에 공개하거나 배포하지 않는다.
> 자세한 이유는 아래 "공개하지 않는 이유" 참고.

## 설치

```bash
pip3 install yfinance pandas requests lxml
```

## 사용법

```bash
cd tools/scanner

python3 scan.py                      # 한국+미국 전체, 최근 5거래일 신호
python3 scan.py --market kr          # 한국만
python3 scan.py --market us --days 3 # 미국, 최근 3거래일
python3 scan.py --pattern 골든크로스 "52주 신고가 돌파"
python3 scan.py --limit 30           # 30종목만 (빠른 테스트)
python3 scan.py --refresh            # 시세 캐시 무시하고 새로 받기
```

리포트는 `report/scan-<날짜시각>.html`로 저장된다. 브라우저로 열면
패턴별 탭 필터와 종목별 미니 캔들 차트를 볼 수 있다.

## 탐지하는 패턴

| 패턴 | 조건 | 사이트 글 |
|---|---|---|
| 골든크로스 | 5일선이 20일선 상향 돌파 | `moving-average` |
| 데드크로스 | 5일선이 20일선 하향 이탈 | `moving-average` |
| 52주 신고가 돌파 | 250일 최고가 돌파 + 거래량 1.2배↑ | `breakout-52week` |
| 쌍바닥 넥라인 돌파 | 비슷한 저점 2개 후 넥라인 종가 돌파 | `double-top-bottom` |
| 갭 상승 | 전일 고가 대비 +3%↑ 시가 + 거래량 1.5배↑ + 양봉 | `gap-trading` |
| RSI 과매도 반등 | RSI 30 아래에서 30 위로 회복 | `rsi` |
| 볼린저 스퀴즈 돌파 | 밴드폭 6개월 최저권 수축 후 상단 돌파 | `bollinger-bands` |

## 데이터

- 출처: Yahoo Finance (yfinance), 일봉 약 2년치
- 종목 리스트: 코스피200은 네이버 금융, S&P500은 위키피디아
- 시세·종목 리스트 모두 `.cache/`에 **하루 단위로** 캐시된다. 같은 날 재실행은 빠르다.
- 가격은 **수정주가**(액면분할 반영) 기준이다.
- 장중에는 당일 봉이 미완성일 수 있다. 리포트 상단의 "데이터 최신 봉" 날짜를 확인할 것.

## 한계 — 반드시 알고 쓸 것

1. **오탐이 섞인다.** 기계적 규칙이라 사람 눈에는 패턴이 아닌 것도 걸린다.
   리포트는 "확인할 후보 목록"이지 결론이 아니다. 차트를 직접 봐야 한다.
2. **미래를 예측하지 않는다.** 과거에 같은 패턴이 통했다는 사실이 이번에도
   통한다는 뜻은 아니다. 탐지된 신호의 상당수는 실패한다.
3. **생존편향에 주의.** 사이트의 실제 사례 차트는 성공 사례가 섞여 있지만,
   이 스캐너는 결과를 미리 알 수 없는 "지금 막 발생한" 신호를 보여준다.
   둘을 같은 것으로 착각하면 안 된다.
4. **거래가 얇은 종목일수록 오탐이 늘어난다.** 코스피200·S&P500으로 범위를
   제한한 이유다.

## 공개하지 않는 이유

이 도구를 개인용으로 두고 웹에 공개하지 않는 데는 두 가지 이유가 있다.

- **데이터 재배포**: 소수 사례를 교육용으로 인용하는 것과, 매일 수백 종목의
  시세 스캔 결과를 게시하는 것은 성격이 다르다. 후자는 Yahoo Finance 약관상
  재배포에 해당할 소지가 있다.
- **규제**: "오늘 A종목에 골든크로스 발생" 같은 신호를 불특정 다수에게
  제공하면 투자 조언으로 볼 여지가 있다. 국내에서는 유사투자자문업 신고
  의무가 문제될 수 있고, 광고 등 수익이 결합되면 더 그렇다.

공개를 검토한다면 그 전에 위 두 가지를 먼저 확인해야 한다.
